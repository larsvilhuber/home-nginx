Help

What to do with each kind of disc or object, step by step. Pick what you have in your hands.

CD with a barcode

When to use: a music CD whose case has a barcode (UPC/EAN), that you want to rip and play.
  1. Put the CD in the ARM drive. ARM rips it by itself; you can follow it in CD Ripper (under "Elsewhere" in the menu). Wait until it has finished.
  2. Open Check → CD. Tap Scan barcode and hold the case barcode to the camera (or type it in the box and tap Look up).
  3. Check asks MusicBrainz and shows the albums that could be this CD. The fresh rip is marked ripped (purple). Tap it.
  4. Tap Save + import. The rip is moved into the library and Lyrion rescans.
  5. Open Play, scan the same barcode: it plays.
What you should see "Imported. Waiting for Lyrion to rescan…", then "Imported and in the library." with a green Imported badge. About 30 s later the record is sent to Shelf by itself (tag cdcheck, plus numérisé because it plays); the card then shows "Shelf: <location> · item #N ↗".
The CD replaces an mp3 album already in the library
  • Before importing, move the old mp3 folder to /media/space2/music.mp3-backup/, keeping its path under the library root. For example: 
    mv /media/space2/music/Dizzy_Gillespie_-_Lady_Be_Good /media/space2/music.mp3-backup/
    Never delete it, and never make another backup folder. The import refuses to run while a folder with the same name is still in the library.
  • If the barcode already points at the old mp3 album (Check shows a green Confirmed card), keep that barcode: tap Change, pick the ripped entry and tap Save + import. Do not make an LV label for it.
If something goes wrong
  • "not in MusicBrainz": type the artist or album in or search artist / album and tap Search. The barcode stays armed, so you can still pick the rip and Save + import.
  • No ripped entry: ARM has not finished, or the rip has a different name. Search by artist / album. If you only tapped Save, the card shows Ripped, waiting to import: tap Import to library.
  • "Imported; Lyrion has not listed it yet": wait a minute and look the barcode up again.
  • Wrong album saved: tap Change and pick again (or Forget).

CD without a barcode

When to use: a CD with no barcode on the case (or only a record-club number such as D136343).

Club number (D-code) printed on the case

  1. Rip the CD in ARM as usual.
  2. In Check → CD, scan the club code or type it in or type barcode / catalog no. and tap Look up. It is used like a barcode.
  3. MusicBrainz usually does not know club numbers. Then search the artist / album below; pick the ripped entry and tap Save + import (or the library album and Save).

No code at all: make an LV label

  1. Rip the CD in ARM.
  2. Open Tag → CD. Search the artist / album (an empty search lists what was ripped recently). Leave hide albums that already have a barcode ticked.
  3. On the album (under "Ripped, not yet in the library" or "In the library"), tap Make label. The new LV code goes into the Print queue at the bottom.
  4. Print it: Print on labeller (or wait for a full sheet). Answer the yellow box. See Printing labels.
  5. Stick the label on the case.
  6. For a rip: scan the new label in Check → CD; it shows Ripped, waiting to import; tap Import to library.
What you should see The album's badge goes from no barcode to "LV… queued", then "LV… printed" once you confirm the print.
If something goes wrong
  • Label lost or damaged: on the album in Tag → CD, tap Print again.
  • Album has a barcode already but you still want an LV: untick the box and use Label anyway.

New DVD: maybe the film is already ripped

When to use: a DVD or Blu-ray that is not catalogued yet. The film itself may already be in the film library (ripped from another copy, or downloaded), so look before you rip.
  1. Make sure the disc is not catalogued: in Check → DVD tap Scan barcode (or type the code and tap Check). "Nothing is catalogued under this code." means carry on. If it shows the film, you are done.
  2. Open the Cataloguer, Look it up. Set the kind to DVD (or Blu-ray), type the title (films are found by title) and tap Search. Tap the right TMDB result.
  3. If the film is in the library, a ticked box appears: This film is already in your library: … — link this disc to it. Leave it ticked (pick the version if there are several).
    • Code: Use the barcode on the item and scan the case UPC, or Make an LV label if the case has none.
    • Choose the Shelf location, then tap Catalogue it.
    • Do not rip the disc.
  4. If no box appears, the film is not in the library: rip it.
    • Put the disc in the ARM drive and wait for the rip.
    • In Tag → DVD, under 1. Ripped, waiting to import tap Refresh, then Choose on the rip.
    • 2. Files: check which file is the main film. 3. Identify the film: search TMDB and pick it. 4. Code: Use the case barcode or Make an LV label.
    • Tap Preview, read the plan, then Import.
What you should see Cataloguer: "Catalogued as …" and "Linked to the film in your library: … — it plays from CD / DVD Play." Tag import: a green Imported card with a button Check … in Check (DVD); all rows green there. Shelf gets the item about 30 s later.
If something goes wrong
  • No box, but you know the film is ripped (different title, other language): catalogue the disc anyway, then in Check → DVD scan it and use Link to a film already in the library; search the library by another title.
  • The same thing works from Tag → DVD → Catalogue only (not ripped) (no location choice there).
  • Import shows This film already exists in the library.: see Second rip of a film.
  • A rip is greyed "not ready": ARM is still working. Wait, then Refresh.

New rip of a film already in the library

When to use: you ripped a DVD whose film is already in the library (another cut, a better copy) and want to keep both. Both are kept as versions; nothing is replaced.
  1. Import it in Tag → DVD as usual (Choose, identify, code).
  2. You can fill Version (optional, e.g. Director's Cut) straight away. If you do not, Preview stops with a yellow box: This film already exists in the library. It lists the existing versions.
  3. Type a version label (for example "Director's Cut", "Extended", "DVD") and tap Use it.
  4. Check the plan, then Import.
What you should see The file goes in the film's folder as <Title> - <version>. In Play, this disc's code plays this version; the other disc plays the other one.
If something goes wrong
  • Already catalogued. with a code: that code (case barcode) is already used. If it really is a second copy, tap Import anyway; otherwise follow the check … link.
  • You do not want a second file: do not import. Catalogue the disc and link it to the existing film (New DVD, step 3).

DVD, Blu-ray or VHS you won't rip

When to use: you only want the film on the shelf list (where it is, which code), not playable.
  1. Open the Cataloguer, Look it up.
  2. Kind: DVD, Blu-ray or VHS. Type the title (and year if you know it), tap Search, pick the TMDB result.
  3. Code: Use the barcode on the item (scan the case) or Make an LV label (tapes usually have none).
  4. Choose the Shelf location and tap Catalogue it. Print the LV label if you made one and stick it on the case.
What you should see "Catalogued as …", then "Waiting for Shelf… (sent about 30 s after saving)" turning into "In Shelf: item #N ↗". In Play the code says "Catalogued, not playable".
Quicker, without location Tag → DVD → Catalogue only (not ripped): kind, search TMDB (title), code, Add to catalogue. It goes to the default location (Magog / Sous-sol); change it in Shelf if needed.
If something goes wrong
  • The film turns out to be in the library: keep the ticked This film is already in your library box; the disc will then play.
  • TMDB finds nothing: fill the title by hand under 2. Record (or By hand).

Vinyl or cassette with a barcode

When to use: a record or tape whose sleeve or case carries a barcode.
  1. Open the Cataloguer, Look it up. Kind: vinyl or cassette.
  2. Tap Scan next to barcode on the sleeve / case and hold the barcode to the camera. The search runs by itself (MusicBrainz and Discogs).
  3. Pick the pressing in your hands: compare label · catalogue number, format and country.
  4. Code: Use the barcode on the item is already chosen with the scanned code. No label to print.
  5. Choose the Shelf location and tap Catalogue it.
What you should see "Catalogued as <barcode>", then "In Shelf: item #N ↗". The catalogue number shows in the Shelf item's notes as [cdcheck <code>] Cat. no. … (Shelf has no field for it).
If something goes wrong
  • Nothing found by barcode: clear it and search by catalogue number or title + artist instead (see Vinyl without barcode), then type the barcode under Use the barcode on the item.
  • Already catalogued: tap Show … to see it, or It is a second copy: catalogue anyway.

Vinyl with no barcode at all

When to use: an older record with no barcode anywhere. You find it by its catalogue number and give it an LV label.
  1. Open the Cataloguer, Look it up. Kind: vinyl.
  2. Type the catalogue number from the label or spine in catalogue no. (e.g. SHVL 804), exactly as printed, and tap Search. Matching is exact: if nothing comes, try again with and without spaces or dashes (SHVL 804, SHVL804, SHVL-804).
  3. Still nothing: search by title + artist instead (catalogue number empty).
  4. Pick the pressing: same label, same catalogue number, same country as your copy.
  5. Code: Make an LV label (queued for printing below; stick it on the sleeve).
  6. Choose the Shelf location and tap Catalogue it.
  7. Print the label on the labeller (Print on labeller in the Print queue lower down) and confirm in the yellow box.
  8. Stick the label on the sleeve, not on the record.
What you should see "Catalogued as LV…" and "An LV label was queued: print it below and stick it on the sleeve." Shortly after, "In Shelf: item #N ↗"; the catalogue number is in the Shelf notes line.
Other ways
  • Not in MusicBrainz or Discogs: tap By hand and fill 2. Record yourself (title, artist, Label / publisher, Catalogue no., country).
  • Shelf's own Music page (hidden from Shelf's menu) also searches MusicBrainz by title / artist, barcode or catalogue number (exact matches; partial numbers often fail). An item added there has no LV code yet: link it afterwards with Already in Shelf.
If something goes wrong
  • "MusicBrainz: …" under the Search button (busy): wait a minute and search again; Discogs results still show.
  • Label did not print: see Printing labels.

Something already in Shelf

When to use: the item was added by hand in Shelf (or on Shelf's Music page), and you want the media tools to know it, without a second Shelf item.

Not catalogued here yet: scan it in Check

  1. Scan the code that is on the item (its Shelf label CV-000123, the sleeve or case barcode, an LV label) in Check, either tab. (Play shows the same card.)
  2. The card says In Shelf only: "In Shelf: title — artist · location · item #N ↗". Tap Add to Media tools.
  3. The record is made with Shelf's title, artist, year and, for music added from Shelf's Music page, its catalogue number, label, country and format. Check then shows it again as Catalogued, linked to item #N. A CD can then be paired with its library album with Change (or tap Look for it in the library first).
  4. If the card says "Media tools already has this Shelf item as code", the item carries another code too: tap Show code, or Add … too to make this code a second way in.

Not catalogued here yet: from the Cataloguer

  1. In the Cataloguer, tap A Shelf item. (Typing a barcode Shelf knows under Look it up jumps here too.)
  2. Scan or type its Shelf label (CV-000123) or its retail barcode, or paste its Shelf address (https://hibou:18443/item/…). Tap Find.
  3. "Found Shelf item #N" fills the form (with Shelf's catalogue number, label, country and format for music from Shelf's Music page). Choose a code if it has none (Use the barcode on the item or Make an LV label), then Catalogue it.

Already catalogued here, but not linked

  1. Scan the code in Check → CD or Check → DVD. The card says "Not in Shelf yet." Tap Link to Shelf item….
  2. Type the CV- code, barcode, Shelf address or item number (or Scan), tap Find, then Link … to this item.
  3. If the Shelf item has another UPC, a button Replace the Shelf item's UPC (…) with … appears; use it only when the code on the item is the right one.
  4. One Shelf item for several discs (a set): tick Link this code too (another disc of the same set).
What you should see "Linked to Shelf item #N." and "Scan check in Shelf: … finds this item". No new Shelf item is made and the location is not changed.
If something goes wrong
  • The card says Shelf already has an item for this (#N), made by hand: the automatic push stopped instead of making a duplicate. The link box opens with #N filled in: tap Find, then link.
  • "Shelf has no such item.": check the number in the item's address.
  • Check says "Nothing is catalogued under this code" or "Shelf did not answer": Shelf was down or slow; the media tools stop asking it for 20 seconds. Scan again a little later.

Books, games, puzzles

When to use: anything that is not music or film. These are added in Shelf itself, not here.
  1. Open Shelf and add the item there (its scanner reads the ISBN / barcode). Board games and puzzles have their own types.
  2. For a label: on the item, use Assign code on each copy, one copy at a time. Never use the bulk Assign codes.
  3. Print it on the labeller with Shelf labels: Item number (the number in the item's address), Show labels, then Print on labeller.
Good to know The Cataloguer does not make new Shelf items for books or games ("Add books and games in Shelf, then start from "A Shelf item"."). Scanning a CV- label in Play shows "In Shelf, not playable" with its location.
If something goes wrong
  • "Shelf has no labels for that selection": the copy has no code yet; assign one first.

Printing labels

When to use: LV labels are waiting in the print queue, or a Shelf label (CV-…) needs printing or reprinting.

LV labels (made in Tag or the Cataloguer)

  1. The Print queue is at the bottom of Tag (CD and DVD labels together) and of the Cataloguer.
  2. Labeller (Supvan, 40 × 30 mm): Print on labeller prints every queued label, one by one; Label on a line prints just that one. Remove takes one out of the queue.
  3. Sheet printer: when the sheet is full the button reads "Print sheet (N)" (before that "Print anyway (N)"). Choose Letter or A4; a PDF opens to print. Cut along the dashed lines.
  4. A yellow box asks Did the labels come out of the label printer? (or Did the sheet print?). Tap Yes, mark printed, or No, keep queued to try again.

Shelf labels (CV-…), and reprinting any label

  1. Open Shelf labels. Choose Shelf sheet URL, Item number, Code range or Codes (LV codes work here too), then Show labels.
  2. Untick what you do not want, then Print on labeller. Confirm with Yes, all good or No, print some again.
  3. From a Shelf label sheet on a computer: drag the Print on labeller bookmark (on that page) to the bookmarks bar once, then click it on any Shelf sheet page. On a phone, paste the sheet's address in Shelf sheet URL, or use Copy bookmark address.
Reprinting A CD's LV label: Print again in Tag → CD. Any LV or CV- code: Shelf labels → Codes. Every sheet is also saved as a PDF in /home/squeezebox/cdcheck-api/sheets/ (open PDF again).
If something goes wrong
  • "Sent N, then stopped: …": the printer failed on one label; the rest stay queued. Confirm the ones that printed, check the printer (on, tape loaded), then print again.
  • Nothing came out: No, keep queued, fix the printer, try again.

Playing a CD or a film

When to use: you want to hear a CD or watch a film by scanning its case.
  1. Open Play. In the first list choose the Lyrion player for music (— choose a player —).
  2. For films, choose the TV in the second list (— film on: choose a device —). The TV must have Jellyfin open and signed in, or it is not listed; open it, then tap ↻ next to the list.
  3. Tap Start scanning and show the barcode or LV label. The camera stays on for the next one. You can also type the code and tap Play.
  4. A disc with several films asks Which film on …?: tap one.
What you should see "Playing: …" (music, with ⏮ ⏯ ⏭ ⏹) or "Playing on <TV>: …" (film, with ⏯ Pause / resume and ⏹ Stop). Below, "Shelf: <location> · item ↗" says where the case lives.
If something goes wrong
  • "Catalogued, not playable": the disc is only catalogued. Rip it, or link it to a film in the library (New DVD).
  • "In Shelf, not playable": a Shelf-only item (book, game, …).
  • "not paired with an album yet. Pair it in Check.": see CD with a barcode.
  • "Your saved film device is not open. Choose another.": open Jellyfin on the TV, sign in, ↻.
  • "Camera needs HTTPS": open the page as https://hibou/….

When something's wrong

When to use: a red row, an error message, or something that did not happen.
Check → DVD shows red rows The rows File, List row, Symlink, Jellyfin must all be green. Tap Rebuild + rescan (can take a while), then Re-check. If File stays red the file was moved or deleted: use Link to a film already in the library to point the code at the right film.
Check or Play says "unknown" for something that is in Shelf Unknown codes are looked up in Shelf too (In Shelf only → Add to Media tools, see Already in Shelf). If Shelf did not answer, Check says so: wait a little and scan again. If Shelf answers but does not know the code, the code is not on the Shelf item: link it with the Cataloguer's A Shelf item (item number or Shelf address).
Shelf did not get the item
  • Check (either tab) shows "Shelf push: <error>"; the Cataloguer's Recently catalogued shows "Shelf error". The full list is at /cdcheck-api/shelf/status (last_errors, queue waiting / retry / blocked).
  • "already exists (item N) -- link by hand": tap Link to Shelf item… on the record and link it to #N (Already in Shelf).
  • Other errors (Shelf was down): push again from a shell on hibou: 
    curl -sk -X POST https://hibou/cdcheck-api/shelf/push -H 'Content-Type: application/json' -d '{"code":"LV00123"}'
    or link it by hand as above.
The TV is not in Play's film list Open Jellyfin on the TV and sign in, then ↻. "Jellyfin unreachable" means the Jellyfin server itself is down.
A label did not print Answer No, keep queued (or No, print some again on Shelf labels), check the labeller, print again. See Printing labels.
MusicBrainz is "busy" MusicBrainz often answers 503 when it is busy. The pages retry a few times; if it still fails ("MusicBrainz: …" in the Cataloguer, "Error: MusicBrainz HTTP 503" in Check), wait a minute and try again.
A CD scans as "no library album yet (still rescanning?)" Lyrion has not finished its rescan after an import. Wait, then scan again.
