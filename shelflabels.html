Shelf labels

Print Shelf's own copy labels (codes like CV-000012, with the title) one at a time on the label printer (Supvan, 40 × 30 mm), instead of on an Avery sheet. Shelf is only read.
Did the labels come out of the label printer?

1. Which labels

In Shelf: Labels → pick the labels → the sheet page opens. Paste that page's address here (or use the bookmark below).
Every copy of one Shelf item that has a code. The number is in the item's address: …/items/786.
Shelf's generated codes, by number (hand-typed codes such as LV… are not in a range: use "Codes").
Any copy codes Shelf knows (CV-…, LV…, …), separated by spaces, commas or new lines.

2. Print

One label at a time, a few seconds each. If one fails, the rest are not sent.

Bookmark for Shelf's sheet pages

Computer: drag this button to the bookmarks bar.
Print on labeller
  1. In Shelf, open Labels and choose labels as usual (one item, a code range, a location…). The label sheet opens.
  2. On that sheet page, click the Print on labeller bookmark: this page opens with those labels.
  3. Untick any you do not want, then Print on labeller.
